##  ¿Por qué creamos Silénciate? (Descripción del Problema)
En la **Institución Educativa Francisco Antonio Zea**, hemos evidenciado un alto nivel de ruido durante las clases. Esta situación está relacionada con la **contaminación acústica**, una forma de polución ambiental que puede alterar el bienestar, generar estrés y dificultar los procesos de aprendizaje.

**Dificultades principales:**
*   Los estudiantes no son plenamente conscientes del nivel de sonido que generan.
*   No existe un sistema de monitoreo permanente ni una herramienta visual o interactiva en tiempo real.
*   Los llamados de atención verbales suelen ser repetitivos y poco efectivos al no haber una retroalimentación inmediata.

---

## ¿Cómo solucionaremos este problema? (Objetivo General)
Decidimos crear una **aplicación didáctica** cuyo principal propósito es medir y transformar el ruido en una herramienta que permita generar conciencia en los estudiantes. La aplicación busca representar de una manera sencilla y visual los niveles de ruido producidos durante las actividades cotidianas, permitiendo que los estudiantes comprendan cuándo el ruido supera niveles adecuados.

No se busca únicamente medir los decibeles, sino utilizar la información obtenida como un **recurso educativo** que motive a los estudiantes a modificar sus hábitos y asumir una mayor responsabilidad frente al ambiente escolar.

---

##  Objetivos Específicos
*   **Analizar** las necesidades del entorno escolar e identificar los requerimientos funcionales del sistema.
*   **Diseñar** una interfaz intuitiva para que el docente seleccione grupos, tiempos de medición y visualice los datos.
*   **Desarrollar** el sistema utilizando aplicaciones móviles y el micrófono del dispositivo para procesar el sonido.
*   **Implementar** mecanismos de clasificación mediante indicadores gráficos y colores (Bajo, Moderado, Alto).
*   **Integrar** analíticas para generar reportes con promedios de ruido y horarios con mayor afectación.
